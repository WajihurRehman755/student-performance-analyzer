# Student Study Performance Analyzer

## About
A simple Python program that analyzes marks in three subjects and generates a student performance report.

## Features
- Accepts three subject names and marks.
- Validates marks between 0 and 100.
- Handles non-numeric input.
- Checks for empty and duplicate subject names.
- Calculates total marks, percentage, and average.
- Identifies the highest and lowest marks.
- Assigns a grade based on the percentage.

## Technologies
- Python 3

## How to Run
1. Install Python 3.
2. Open Command Prompt in the project folder.
3. Run:

   ```bash
   python student_analyzer.py
   ```
